# ADR 0003: VNC のウィンドウマネージャーは IceWM にし、Wine の窓の枠は Wine が描く

- 状態: 採用（2026-11-03）。ADR 0002（ウィンドウマネージャーを使わない）を置き換える。
- 関連: ADR 0002、RUNBOOK「MT の固まりの切り分け」

## 背景

- ADR 0002 で、MT4 が固まる原因の wm2 をやめ、ウィンドウマネージャーなしにした（v1.7.0）。
- なしでは窓に枠が無く、動かすことも大きさを変えることもできない。MT を 2 つ以上動かしたときの切り替えもできない。
- 求める条件: 軽い、シンプル、窓の各辺をつかんで大きさを変えられる、MT が固まらない。

## 検証（2026-11-03、GCE e2-small、Ubuntu 24.04 minimal、Wine 10.0、MT4 build 1492）

IceWM 3.4.5（`--no-install-recommends`、インストールサイズ約 2.4MB、動作中のメモリ約 17MB）で次を確かめた。

- wm2 で固まった操作（デモ口座作成の「完了」、「ツール」メニュー）と「記事」タブで、固まらない。CPU も張り付かない。
- クリックがずれない。
- MT4 を 2 つ動かし、タスクバーのボタンで切り替えられる。
- IceWM の既定のままでは、MT4 は画面いっぱいの大きさで開き、IceWM の枠が画面の外に出るので辺をつかめない。IceWM 側から大きさを変えても、MT4 が元の大きさに戻す。
- Wine の `HKCU\Software\Wine\X11 Driver` の `Decorated=N`（Wine が自分の窓の枠とタイトルバーを描く）にすると、MT4 は普通の大きさの窓で開く。上下左右の辺と角で大きさを変えられ、タイトルバーで動かせ、最小化・最大化・閉じるのボタンも使える。この設定は、設定後に作られた窓から効く。

## 決定

1. VNC のウィンドウマネージャーは IceWM にする。`icewm` を `--no-install-recommends` で入れ、`templates/xstartup` で `icewm &` を起動する。wm2 は入れない。
2. Wine の prefix に `Decorated=N` を設定する。インストーラを実行するたびに設定する（既存の prefix にも）。
3. 既存の `~/.vnc/xstartup` は、旧テンプレートの `x-window-manager &`（wm2）と、v1.7.0 が書いたコメントの行のどちらかに完全一致する行を `icewm &` に置き換える。元のファイルは `~/.vnc/xstartup.bak.<日時>` に残す。すでに icewm を起動しているもの、独自に書き換えたもの、シンボリックリンクは変えない。
4. インストーラを再実行しない既存の環境の手順は RUNBOOK に書く。

## 結果

- 窓の枠・移動・大きさの変更・タスクバーでの切り替えができる。
- Wine 以外の窓（xterm など）の枠は IceWM が描く。IceWM の枠のタイトルでは日本語が化けることがある（MT の窓は Wine が描くので影響しない）。
- 入っている wm2 のパッケージは消さない（使わないだけ）。

## 見直しの条件

IceWM の下で MT が固まる事例が出たら、同じ再現手順で別の軽いウィンドウマネージャーを試す。
