# 契約テンプレ: bash 関数（common.sh 等）

対象: `common.sh` に定義され、他スクリプトから `source` して呼ばれる関数（`atst_*` ヘルパ等）。シェル関数は戻り値（exit status）・標準出力・グローバル変数・副作用で結果を返すため、それらを**明示的に契約化**する。

## 記入項目

| 項目 | 書き方 |
|---|---|
| 呼び出し形 | `func_name <arg1> <arg2>` と各引数の意味 |
| 消費するグローバル / 環境変数 | 関数が前提とする `ATST_*` 等のグローバル（呼び出し前に設定されていること） |
| 標準出力 | 何を stdout に出すか（呼び出し側が `$(...)` で受ける値か、ログか）。**秘匿情報を出さない** |
| 戻り値（exit status） | `return 0` / 非 0 の意味。真偽判定に使われるか |
| 副作用 | グローバル変数の書き換え・ファイル I/O・外部コマンド実行・LINE 送信など |
| 純粋性 | 入力が同じなら同じ結果か（時刻・乱数・外部状態に依存するなら明記） |
| エラー時の挙動 | 前提不成立・外部コマンド失敗時に return するか、呼び出し側へ伝播するか |

## 記入テンプレ

```markdown
### `<func_name>` (`common.sh`) — 新規 / 改修

- 呼び出し形: `<func_name> <arg1> <arg2>`
- 消費するグローバル: `<VAR>`（呼び出し前に設定必須）
- stdout: <受け取る値 / ログ>（出さないもの: トークン・口座情報・パスワード）
- return: 0 = <真 / 成功> / 非 0 = <偽 / 失敗（意味）>
- 副作用: <グローバル書き換え / ファイル / 外部コマンド / LINE 送信 / なし>
- 純粋性: 副作用なし / あり（<時刻・ファイル・ネットワーク>に依存）
- エラー時: <return 非 0 / 中断 / 呼び出し側に委ねる>
- 改修の場合の差分:
  - 現契約（コードから抽出）: <現状の引数・stdout・return・副作用>
  - 変更点: <追加 / 緩和 / 強化>
  - 後方互換: <破壊あり（呼び出し元 N 件: `grep -rn '<func_name>'`）/ なし>
```

## 観察可能な AC への落とし方

| 契約 | 観察可能な AC |
|---|---|
| return の意味 | `<条件>で呼ぶと return 0、<別条件>で非 0`（`func ...; echo $?`） |
| stdout の形式 | `出力が <期待文字列/形式> に一致する`（`[ "$(func ...)" = "..." ]`） |
| グローバル前提 | `<VAR> 未設定で呼ぶと非 0 で返る（無言で誤動作しない）` |
| 純粋性 | `同じ引数・同じグローバルで 2 回呼ぶと同じ stdout / return` |
| 秘匿情報を出さない | `stdout にトークン・パスワード・口座情報が含まれない` |

呼び出し元は `grep -rn '<func_name>' *.sh` で洗い出し、後方互換の破壊があれば全呼び出し元を同じ PR で直す。

**書いてはいけない AC**: 「正しく動作する」。反証条件が無い AC は Phase 1 の QA 視点が block する。
